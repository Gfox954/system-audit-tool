# System Audit & Security Check (Python)

This project is a lightweight automation script that collects system health,
resource usage, running processes, and Windows Defender security status.

## Features
- CPU, RAM, Disk usage
- OS and hardware info
- Top running processes
- Windows Defender security status
- Outputs results to JSON

## How to Run
pip install psutil
python system_audit.py

## Output
A file named `system_audit_report.json` is generated with full system details.

## Purpose
This project demonstrates Python automation skills for IT Support,
SysAdmin, and cybersecurity environments.
